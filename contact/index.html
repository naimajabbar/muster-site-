What to include in your message

The more detail you include, the faster we can help. Try to include:

  • Device model — e.g. iPhone 16 Pro, Samsung Galaxy S24
  • OS version — e.g. iOS 26.0, Android 15
  • App version — find this in Muster → Settings → About
  • Description — what happened, what you expected, and any steps to reproduce the issue
  • Screenshots — optional, but helpful for visual bugs
